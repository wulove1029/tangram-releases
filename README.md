# Tangram

請依需要選擇版本，解壓縮到各自的資料夾後執行 Tangram.exe：

- [MCP 版：有 MCP Server 功能](https://github.com/wulove1029/tangram-releases/releases/download/v1.3.1/Tangram-MCP-1.3.1-win-x64.zip)
- [一般版：無 MCP 功能](https://github.com/wulove1029/tangram-releases/releases/download/v1.3.1/Tangram-Standard-1.3.1-win-x64.zip)

兩版使用同一組啟用密碼，首次輸入一次即可，之後開啟或更新不用重填。MCP 版只接收 MCP 更新，一般版只接收一般版更新。

舊 1.2.x 通用包沒有版別識別，第一次請手動下載對應版本。完全結束舊程式後，將原本 data 資料夾複製到新版 Tangram.exe 旁，保留原資料作備份。啟用狀態與筆記均保存在 data。

一般版同時關閉 MCP 畫面入口與後端路由，並非只隱藏選單。MCP 版已實跑協定、讀寫筆記與重啟保存測試。
